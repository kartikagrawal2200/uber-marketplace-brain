# Data Directory

## ⚠️ ALL DATA IN THIS DIRECTORY IS SYNTHETIC

No real Uber trip data, driver data, or user data is used in this project.
All datasets are procedurally generated by the simulator.

## Contents

### synthetic/
Auto-generated by the simulator engine. Files appear after running the simulation.

| File | Description |
|------|-------------|
| `demand_log.csv` | Per-tick, per-zone demand counts (TODO: add CSV export to engine) |
