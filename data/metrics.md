# Data Metrics & Provenance

> ⚠️ **All data in this project is SYNTHETIC** — generated by the simulator with seed=42.

## Simulation Parameters

| Parameter | Value | Source |
|-----------|-------|--------|
| Number of zones | 12 | Designed (see city.py) |
| Number of drivers | 30 | Configurable (default) |
| Simulation seed | 42 | Fixed for reproducibility |
| Tick interval | 5 seconds (real) / 30 seconds (simulated) | Config |
| Base demand rates | 0.8–5.2 requests/tick | Estimated from Uber blog posts |
| Weather Markov chain | See traffic_weather.py | Inspired by meteorological data |

## What is NOT Real

- ❌ No real GPS coordinates (zones are abstract)
- ❌ No real trip durations (uniform 4-tick placeholder)
- ❌ No real driver earnings (fixed $12.50 stub fare)
- ❌ No real traffic data (random-walk congestion model)
- ❌ No real user accounts (mock IDs used)

## What Could Be Made Real

- ✅ Zone base demand rates: calibrate against public Uber movement data
- ✅ Weather multipliers: calibrate against weather/ride correlation studies
- ✅ Event multipliers: calibrate from stadium capacity and rideshare usage data
- ✅ Trip durations: use real city OD matrices (e.g., from OpenStreetMap routing)
